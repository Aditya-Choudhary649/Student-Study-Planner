# Student Study Planner

## Introduction

Student Study Planner is a beginner-friendly Python project designed to help students manage their study tasks.

## Features

- Add new study tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
- Edit existing tasks
- View study statistics
- Save tasks using JSON
- Load saved tasks when the program starts
- Basic error handling

## Technologies Used

- Python
- JSON

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python Student_Study_Planner.py

## Data Storage

The program uses a file called `tasks.json` to save the user's tasks.

Each task contains:

- Subject
- Task
- Deadline
- Completion status
